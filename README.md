# Last Stand — Дорога мёртвых

Мобильный аркадный survival-шутер (веб + PWA). Веди отряд выживших влево-вправо, отряд стреляет сам.

## Запуск

```bash
npm install
npm run dev            # http://localhost:5173, в локальной сети — по адресу из вывода (Network)
npm run build          # продакшен-сборка в dist/ (с service worker для офлайна)
npm run preview        # проверить сборку
npm run simtest        # бот проходит всю кампанию без браузера: баланс + производительность
```

На телефоне: открыть адрес из `npm run dev` (телефон в той же Wi-Fi сети) или задеплоенную сборку
и выбрать «На экран Домой» — игра откроется во весь экран как приложение.
Чтобы PWA устанавливалась, сайт должен работать по HTTPS (localhost не в счёт).

Управление: перетаскивание пальцем/мышью в любом месте экрана, или ← → / A D. Пауза — Esc / P.

## Структура

- `docs/GDD.md`, `docs/PLAN.md` — дизайн-документ и план.
- `src/config/` — весь баланс: оружие, зомби, боссы, классы, объекты, уровни, улучшения.
- `src/sim/` — симуляция без DOM (мир, отряд, бой, режиссёр уровня, боссы, бот).
- `src/render/` — процедурные спрайты, фоны глав, эффекты, рендер.
- `src/ui/` — экраны, HUD, стили. `src/meta/` — сохранения и экономика.
- `tools/simtest.ts` — headless-прогон кампании.

Новый враг/оружие/уровень = новая запись в `src/config/`.
